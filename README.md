# 101-WP
A Wordpress plugin for managing the 101 Things in 1001 Days.

## Longer Explanation
There was this thing in the blogosphere (particularly on Livejournal) back in the day, called 101 Things in 1001 Days.  I've done it more than once and I seem to spend almost as much time managing my list and updates as I have actually doing the tasks.  I decided that having a Wordpress plugin to manage most of this would be super useful, and built this, and have installed it on my site.
